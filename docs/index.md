# parallel Documentation

`parallel` provides the `Parallel` runtime class for running a function over a
collection of tasks using a selectable execution engine (threading, joblib,
dask, or ray). Each runtime instance owns its configuration and backend
resources.

- See [API Reference](api.md) for the public class and methods.
- See the project [README](../README.md) for installation, quick start, and
  engine extras.
